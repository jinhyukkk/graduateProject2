## 1. 변경 동기

파일럿 실험(BIRD n=50, HR-DB n=10, GPT-4o-2024-11-20) 결과를 정직하게 반영하기 위한 서사 재프레이밍이다. 초기 가설(NLI 교정 트리거가 EX를 상승시킨다)이 파일럿에서 Null 방향(Full 50.0% vs A1 52.0%, CSR=0%)으로 관측되었고, 이를 **(a) 구조적 원인 분석**, **(b) 관측 사실의 기여 전환**, **(c) 사각지대에서의 NLI 독립 탐지 비율을 풀어쓰기 형태의 보조 관찰로 도입**하여 재정렬했다. 자세한 재프레이밍 설계는 [_workspace/02_narrative_reframing.md](02_narrative_reframing.md) 참조(*용어 주*: 설계서에는 "EIED"라는 임시 약어가 남아 있으나, v0.3 본문에서는 신조어를 도입하지 않고 서술형으로 전환했다).

## 3. 상세 변경

### 3.1 초록 (국문 요약)
- RQ1 원문: "자연어 역번역과 NLI 기반 의미 검증은 기존 실행 기반 검증과 *독립적으로* 기여하는가?" — **제출본과 동일 유지**
- 추가 서술: "파일럿 관찰 결과 … NLI 교정 트리거가 *전역 EX* 에 미치는 기여는 구조적으로 축소되는 한편, 실행 검증이 통과시킨 사각지대 쿼리를 NLI가 독립적으로 포착하는 비율은 뚜렷하게 관측되었다. 본 연구는 ICC를 *교정 트리거* 와 *독립 진단 축* 의 **이원 역할**로 배치하는 운영 원칙을 제시한다."
- BIRD 공식 평가 스크립트 명시

### 3.2 §1.3 연구 기여
- 기여 #1 상승: "ICC 독립 진단 축 설계 + 실행 축 사각지대에서의 NLI 독립 탐지 정량화"
- 기여 #4 강화: "동일 공식 평가 스크립트 사용으로 자체 평가 로직 편향 제거"

### 3.3 §5.3 비교 모델 · §5.4 주요 결과
- 원 논문 vs 본 연구 재실행 설정 차이 표 신설 (백본·SC·k·평가 스크립트)
- 표 2-B에 **난이도별 (simple/moderate/challenging) 컬럼 신설** (BIRD 공식 평가 기준)
- DAIL-SQL·MAC-SQL 재실행 수치 차이의 해석을 "구현 결함"이 아닌 "모델 세대 차이 + SC 생략 복합 효과"로 정정

### 3.4 §6.1 RQ1 고찰 (가장 중요한 변경)
- 3 sub-section 구조:
  - 6.1.1 교정 관점: EX 기여 Null, 구조적 원인(고신뢰 초기 SQL, confidence gating)
  - 6.1.2 진단 관점: 실행 축 통과 오답(사각지대) 중 NLI 독립 탐지 비율을 풀어쓰기 서술로 보고
  - 6.1.3 이원적 결론: 교정 트리거 + 진단 축의 이원 역할 운영 원칙
- HRDB 한글 메타 +20pp 관찰을 "스키마 링킹 품질이 실무 DB의 주된 병목" 보조 증거로 위치

### 3.5 §6.4 결론
- 기여 3개 → 4개 (공정 비교 인프라 별도화)
- 파일럿 한계 명시: "EX 직접 상승 아님, 독립 탐지 지표로서 기여" 서술
- 사각지대에서의 NLI 독립 탐지 비율을 풀어쓰기로 보고 (신조어 도입 없음)
