기업 데이터 접근성 향상을 위한 자기교정 Text-to-SQL 프레임워크
A Self-Correcting Text-to-SQL Framework for Enhancing Enterprise Data Accessibility

저자: 박진혁
소속: 국민대학교 대학원

초록
기업 데이터 활용 수요가 커지면서 SQL 비전문가를 위한 Text-to-SQL과 그 자기교정 기법의 중요성이 높아지고 있다. 그러나 기존 자기교정 연구는 절 단위 추론, 실행 결과 대조, 동치성 검사 등 코드와 실행 측면에 집중되어, 쿼리가 정상 실행되더라도 사용자의 본래 의도와 다른 결과를 반환하는 의도 불일치 오류를 포착하기 어렵다. 본 연구는 다음 두 연구 질문을 다룬다. RQ1. 자연어 역번역과 NLI 기반 의미 검증은 기존 실행 기반 검증과 독립적으로 기여하는가? RQ2. 진단된 오류 유형별로 분기되는 전용 교정 프롬프트는 단일 공용 교정기 대비 교정 정확도를 향상시키는가? 이를 위해 의도 일치 검증기(Intent Consistency Checker, ICC)를 핵심 모듈로 하는 자기교정 Text-to-SQL 프레임워크(SC-TSQL)를 제안한다. ICC는 생성된 SQL을 자연어로 역번역한 뒤 NLI 모델로 원 질의와의 함의 관계를 판정하고, 그 결과를 사전 정의된 오류 유형으로 분류해 유형별 특화 교정 프롬프트로 분기한다. 아울러 데이터 프라이버시 제약 환경을 위해, 기업 HR 데이터베이스의 DDL 구조만 이식하고 합성 행으로 채우는 스키마-온리 평가 프로토콜을 함께 제안한다. 평가는 대규모 cross-domain Text-to-SQL 벤치마크인 BIRD(BIg Bench for LaRge-scale Database Grounded Text-to-SQL) 검증셋에서 선행 모델 DAIL-SQL, MAC-SQL을 동일한 GPT-4o 백본으로 재실행해 공정 비교 환경을 구성하며, 실행 정확도(EA), 유효 효율 점수(VES), 완전 일치(EM)와 본 연구가 제안하는 의도 일치 점수(ICS)로 측정한다. RQ1은 NLI 모듈 ablation으로, RQ2는 분기 교정과 공용 교정기 비교로 검증한다. 본 연구는 의미 검증 차원의 추가와 오류 유형 기반 분기 교정이라는 방법론적 기여와 함께, 원본 데이터 노출 없이 사전 검증이 가능한 평가 프로토콜을 통해 프라이버시 제약 환경에서 Text-to-SQL의 안전한 도입을 지원한다.



Key word: Text-to-SQL, 자기교정, 의도 일치 검증, 자연어 추론(NLI), 오류 유형 기반 분기 교정
